## 📝 README: **Автотесты для API**

### 📌 **О проекте**
Этот проект содержит автоматизированные API-тесты, реализованные с помощью **RestAssured, JUnit 5 и Allure**.  
Тесты проверяют функциональность API **Reqres** и **Rick and Morty**, включая:  
✅ Создание пользователей в Reqres  
✅ Получение данных о персонажах Rick and Morty  
✅ Проверку совпадения расы или местонахождения персонажей

---

### 🛠 **Стек технологий**
- **Java 17** – язык программирования
- **Maven** – система сборки проекта
- **RestAssured** – библиотека для API-тестирования
- **JUnit 5** – тестовый фреймворк
- **Allure** – генерация отчетов

---

### 🚀 **Как запустить тесты?**

#### 🔹 1. **Установите зависимости**
```sh
mvn clean install
```

#### 🔹 2. **Запустите тесты**
```sh
mvn test
```

#### 🔹 3. **Сформируйте отчет Allure**
После выполнения тестов в папке `target/allure-results` появятся данные для отчета.

🌊 **Сгенерировать отчет:**
```sh
mvn allure:report
```
или

🌐 **Запустить отчет в браузере:**
```sh
mvn allure:serve
```
