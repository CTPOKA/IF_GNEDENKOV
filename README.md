## 📝 README: **Автотесты для Jira**  

### 📌 **О проекте**  
Этот проект содержит автоматизированные тесты для Jira, реализованные с помощью **Selenide, JUnit 5 и Allure**.  
Тесты проверяют основные пользовательские сценарии, такие как:  
✅ Авторизация в Jira  
✅ Открытие проектов  
✅ Работа с задачами (создание, изменение, удаление)  
✅ Проверка счетчика задач  

---

### 🛠 **Стек технологий**  
- **Java 17** – язык программирования  
- **Maven** – система сборки проекта  
- **Selenide** – фреймворк для UI-тестирования  
- **JUnit 5** – тестовый фреймворк  
- **Allure** – генерация отчетов  

---

### 🚀 **Как запустить тесты?**  

#### 🔹 1. **Установите зависимости**  
```sh
mvn clean install
```

#### 🔹 2. **Запустите тесты**  
```sh
mvn test
```

#### 🔹 3. **Сформируйте отчет Allure**  
После выполнения тестов в папке `target/allure-results` появятся данные для отчета.  

🌊 **Сгенерировать отчет:**  
```sh
mvn allure:report
```
или

🌐 **Запустить отчет в браузере:**  
```sh
mvn allure:serve
```
